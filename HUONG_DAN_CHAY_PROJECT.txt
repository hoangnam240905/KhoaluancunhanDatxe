1. TỔNG QUAN REPOSITORY
--------------------------------------------------

Hệ thống cho thuê xe du lịch trực tuyến (đồ án CNTT-KLCN108).

Gồm:
- 1 Backend API (ASP.NET Core)
- 1 project test Backend (Backend.Tests)
- 2 ứng dụng Flutter (CustomerApp, DriverApp)
- 4 website Razor Pages (PortalWeb, AdminWeb, CustomerWeb, DispatcherWeb)
- 1 thư mục script SQL Server (Database/) — không bắt buộc khi chạy mặc định

Phụ thuộc:
- Mọi app/web gọi Backend qua HTTP.
- Backend đọc database (mặc định SQLite file carrental.db).
- Website không kết nối database trực tiếp.
- CustomerApp và DriverApp không phụ thuộc nhau.
- Phải chạy Backend trước khi chạy app hoặc web.

Tối thiểu để demo:
Backend + (PortalWeb hoặc CustomerApp).

Hai hình thức thuê (RentalMode):
- WithDriver: Dispatcher gán tài xế + xe (TripAssignment). Tài xế start/complete.
- SelfDrive: Dispatcher gán chỉ xe (AssignedVehicleId), không TripAssignment.
  Dispatcher handover (Assigned → InProgress) và complete (InProgress → Completed).

PortalWeb  /  CustomerApp  /  DriverApp  /  AdminWeb  /  CustomerWeb  /  DispatcherWeb

Admin

H) BACKEND / API

Nguồn: Controllers/, Services/ (PricingService, PaymentService, VehicleInspectionService, BookingFeeService)

AUTH:
- Đăng nhập JWT (POST /api/auth/login)
- Đăng ký khách hàng (POST /api/auth/register) — email, password, fullName, phone?, address?, idNumber?, dateOfBirth?
- Lấy hồ sơ (GET /api/auth/me) — có controller; app/web không gọi trong source

VEHICLES:
- GET /api/vehicle-types (public) — không trả DriverFeePerDay / deposit / included km
- GET /api/vehicles, GET /api/vehicles/{id} (public)
- Thêm / sửa / xóa xe (Admin)
- Không có API CRUD loại xe

BOOKINGS:
- GET /api/bookings/quote (Customer) — query vehicleTypeId, startDate, endDate, estimatedDistance?, rentalMode?
- Tạo đơn (Customer) — PricingService; ghi snapshot; TotalAmount = quote; RentalMode mặc định WithDriver
- Xem danh sách / chi tiết (Customer: đơn mình; Admin/Dispatcher: tất cả)
  Response thêm rentalMode, assignedVehicle, quoted*, finalAmount, fees, finalBaseAmount, totalFees
  totalFees = tổng phí KHÔNG phải ExtraKm (ExtraKm đã gồm trong FinalAmount)
- PATCH /api/bookings/{id}/status (Admin, Dispatcher)
- Đánh giá (Customer) — chỉ Completed + có TripAssignment

PAYMENTS (Customer):
- POST /api/payments — chỉ Deposit; Amount = QuotedDepositAmount; Status Pending; PaidAt null
  Body: bookingId, paymentType, method, transactionRef?
  Balance / Refund → 400 "chưa được hỗ trợ"
  Trùng Deposit Pending/Paid → 400; thiếu snapshot cọc → 400; không phải chủ đơn → 403
- GET /api/bookings/{id}/payments — chỉ chủ đơn
- Không mark-paid, không gateway, Admin/Dispatcher không có API payment

DISPATCH (Dispatcher):
- Xác nhận đơn Pending
- Phân công: WithDriver bắt buộc DriverId + VehicleId → TripAssignment;
  SelfDrive cấm DriverId, ghi AssignedVehicleId, không TripAssignment
- Handover SelfDrive (Assigned): tạo VehicleInspection Handover, InProgress
- Complete SelfDrive (InProgress): Inspection Return; BookingFeeService (FinalAmount + ExtraKm audit);
  Completed; xe Available nếu đang Rented

DRIVERS:
- Danh sách tài xế (Admin, Dispatcher)
- GET /api/drivers/me, GET /api/drivers/me/trips (Driver)
- PATCH /api/drivers/me/status
- accept / start / complete chuyến
  complete: body VehicleConditionRequest optional (EmptyBodyBehavior.Allow);
  luôn tạo Return inspection; tính FinalAmount; ExtraKm fee nếu ExtraKmAmount > 0;
  WithDriver thường không có Handover → km thực tế = EstimatedDistance

GIÁ CHỐT / PHÍ (nội bộ, không endpoint riêng):
- TotalAmount không đổi khi complete
- FinalAmount từ snapshot + km thực tế (thiếu odometer → estimated)
- ExtraKm: một dòng BookingFee, đã gồm trong FinalAmount, totalFees không cộng lại
- LateFee / Fuel: chỉ khi có đơn giá (production không truyền lateFeePerDay/fuelPrice) → không tạo phí
- Damage: không tính; không có bảng giá hư hỏng
- GET không tính lại FinalAmount
- Không backfill đơn cũ / seed

Không có: Payments mark-paid, inspection CRUD, fee CRUD, OTP, email.

I) DATABASE

Nguồn: Backend/Entities, Backend/Data/CarRentalDbContext.cs, Database/02_CreateTables.sql, DbSeeder.cs

Có:
- Roles, Users
- Customers, Drivers
- VehicleTypes (PricePerDay/Km + DriverFeePerDay, SelfDrive*, deposit*)
- Vehicles (CurrentKm; Return có odometer mới cập nhật, không giảm)
- Bookings (RentalMode, AssignedVehicleId, snapshot quoted*, FinalAmount)
- TripAssignments (1-1 Booking; chỉ WithDriver)
- BookingStatusHistory
- Payments (PaymentType nullable: Deposit/Balance/Refund)
- Reviews (cần DriverId từ TripAssignment)
- VehicleInspections (Handover | Return; tối đa 1 mỗi loại / đơn — chặn ở service)
- BookingFees (LateFee, ExtraKm, Fuel, Damage, Other)

Không có trong source:
- RefreshToken
- DriverVehicle
- Bảng đơn giá LateFee/Fuel/Damage trên VehicleType

Seed (chỉ khi chưa có Roles): 2 booking mẫu, 1 TripAssignment đơn #2, 1 Payment Paid đơn #2
(PaymentType null; booking seed không có snapshot giá). FillVehicleTypePricingDefaults chạy mỗi startup
cho cột VehicleType còn NULL — không sửa Bookings.

16. CÁC LỖI THƯỜNG GẶP
--------------------------------------------------

Chỉ ghi lỗi liên quan đến project thực tế.

1) flutter pub get thất bại
   Nguyên nhân: chưa cài Flutter, hoặc Dart < 3.11.1 (pubspec yêu cầu sdk: ^3.11.1)
   Xử lý: cài Flutter, chạy `flutter doctor`, kiểm tra `dart --version`

2) flutter run không thấy Android device
   Nguyên nhân: chưa bật emulator / chưa cắm điện thoại
   Xử lý:
     flutter devices
     Android Studio → Device Manager → Start emulator

3) App không gọi được API (Android Emulator)
   Nguyên nhân: Backend chưa chạy, hoặc đã đổi baseUrl thành localhost
   Xử lý: chạy Backend port 5199; Android emulator cần 10.0.2.2 (đúng với api_config hiện tại)

4) App không gọi được API (Chrome / Windows)
   Nguyên nhân: Backend chưa chạy, hoặc đã sửa tay baseUrl thành 10.0.2.2
   Xử lý: source mặc định localhost cho non-Android; giữ vậy và chạy Backend 5199

5) App trên điện thoại thật không gọi được API
   Nguyên nhân: Android thật vẫn dùng 10.0.2.2 trong api_config
   Xử lý: đổi baseUrl thành http://<IP-LAN-máy-Backend>:5199
          cùng Wi-Fi; tường lửa Windows cho phép port 5199

6) Port 5199 bị chiếm
   Nguyên nhân: Backend cũ còn chạy, hoặc process khác dùng 5199
   Xử lý: đóng process cũ, hoặc đổi Urls rồi cập nhật mọi ApiBaseUrl/baseUrl
   Không force-kill Backend.exe đang lock 5199 trừ khi được giao.

7) dotnet run / restore lỗi thiếu SDK
   Nguyên nhân: chưa cài .NET 10 SDK (csproj TargetFramework = net10.0)
   Xử lý: cài .NET 10 SDK, kiểm tra `dotnet --version`

8) Web chạy nhưng không load dữ liệu
   Nguyên nhân: Backend chưa chạy, hoặc ApiBaseUrl sai
   Xử lý: chạy Backend trước; giữ ApiBaseUrl = http://localhost:5199

9) Database SQLite không tạo
   Nguyên nhân: Backend crash trước EnsureCreated, hoặc không quyền ghi thư mục
   Xử lý: chạy `dotnet run` từ thư mục Backend, xem log
          Không cần tạo file .db thủ công
          Không xóa carrental.db trừ khi được giao

10) Chuyển SQL Server thất bại
    Nguyên nhân: vẫn để DatabaseProvider = Sqlite; connection string sai;
                 chưa chạy script Database/
    Xử lý: chỉ làm nếu thật sự cần SQL Server.
           Chạy 01 → 02 → 03. Sửa DatabaseProvider = SqlServer và DefaultConnection.

11) Flutter Android build lỗi Gradle / CMake / file lock (Windows)
    Nguyên nhân: antivirus khóa file build (repo đã có script)
    Xử lý (chỉ CustomerApp):
      cd CustomerApp
      powershell -ExecutionPolicy Bypass -File .\run_android.ps1
    Hoặc:
      powershell -ExecutionPolicy Bypass -File .\setup_build_junction.ps1

12) CustomerApp cài lên điện thoại ARM thất bại
    Nguyên nhân: android/app/build.gradle.kts có abiFilters.add("x86_64")
    Xử lý: dùng emulator x86_64, hoặc sửa abiFilters cho đúng kiến trúc máy
           (cấu hình Android hiện tại, không phải lỗi Flutter SDK)

13) flutter clean khi build hỏng
      cd CustomerApp
      flutter clean
      flutter pub get
      flutter run
    Làm tương tự với DriverApp.

14) HTTPS redirection
    Backend/Program.cs có app.UseHttpsRedirection()
    Client đang dùng http://localhost:5199
    Nếu gặp redirect/SSL: dùng URL HTTP port 5199 như cấu hình hiện tại.

15) dotnet restore Backend cảnh báo NU1903
    Warning Microsoft.OpenApi (gói kéo theo OpenApi 10.0.3)
    Restore vẫn thành công (exit code 0). Không chặn chạy.
    Không tự ý đổi package version trừ khi được giao.

16) dotnet test / build MSB3027 copy Backend.dll
    Nguyên nhân: Backend.exe đang chạy (thường port 5199)
    Xử lý: test -c Release; hoặc dừng instance test. Không kill API chính nếu đang dùng.

17) POST /api/payments 400 "Đơn này đã có khoản cọc..."
    Đúng hành vi: một đơn chỉ một Deposit Pending hoặc Paid.

18) Đánh giá SelfDrive thất bại
    Backend CreateReview yêu cầu TripAssignment. SelfDrive không có assignment.

19) Complete SelfDrive / Driver 400 "đã có biên bản trả xe"
    Mỗi đơn một Return. Complete lần 2 bị chặn (cũng chặn nhân BookingFee).
