- Logout web = xóa cookie; không POST /api/auth/logout

VEHICLES / TYPES / MAINTENANCE:
- GET /api/vehicle-types (public) — không trả DriverFeePerDay / deposit / included km

- GET /api/vehicles, GET /api/vehicles/{id} (public)
- POST/PUT/DELETE /api/vehicles (Admin)
  Year 1990–2100; LicensePlate unique NOCASE; RegistrationNumber unique ở service
  Không xóa/inactive xe đang hold hoặc open assignment
- GET/PUT/POST/DELETE /api/admin/vehicle-types (Admin)
- POST /api/vehicles/{id}/maintenance; GET history; GET /api/vehicles/maintenance-alerts
  Alert 5000 km / 180 ngày; auto-block lịch mới; không tự đổi Vehicle.Status

BOOKINGS:
- GET /api/bookings/quote (Customer) — query vehicleTypeId, startDate, endDate, estimatedDistance?, rentalMode?
- Tạo đơn (Customer) — PricingService; snapshot; query fromRecommendation → SourceRecommended

  GET /api/bookings list: Driver 403
- PATCH /api/bookings/{id}/status (Admin, Dispatcher) — chỉ Pending/Confirmed → Cancelled
- Đánh giá (Customer) — chỉ Completed + có TripAssignment; 1 review/booking

HỢP ĐỒNG:
- POST/GET /api/bookings/{id}/contract
- POST /api/contracts/{id}/simulate-sign (Customer)
- GET /api/admin/contracts
- Không chữ ký số thật

PAYMENTS (Customer):

  Booking Cancelled → 400 "Không thể tạo tiền cọc cho đơn đã hủy."
- POST /api/payments/{id}/simulate-success → Paid (mô phỏng)
- POST /api/payments/{id}/simulate-failure → Failed + nhả hold
- GET /api/bookings/{id}/payments — chỉ chủ đơn
- GET /api/admin/payments (Admin, read-only)
- Balance / Refund → 400. Không gateway MoMo/VNPay thật

DISPATCH (Dispatcher):
- Xác nhận đơn Pending

  WithDriver bắt buộc DriverId + VehicleId → TripAssignment;
  SelfDrive cấm DriverId, ghi AssignedVehicleId
- Xe/tài đến hạn bảo trì: không nhận lịch mới
- Handover SelfDrive / Complete SelfDrive
- GET /api/dispatch/incidents, GET /api/dispatch/inspections

DRIVERS:

ADMIN KHÁC:

PYTHON:

16. CÁC LỖI THƯỜNG GẶP
--------------------------------------------------

Chỉ ghi lỗi liên quan đến project thực tế.

1) flutter pub get thất bại
   Nguyên nhân: chưa cài Flutter, hoặc Dart < 3.11.1 (pubspec yêu cầu sdk: ^3.11.1)
   Xử lý: cài Flutter, chạy `flutter doctor`, kiểm tra `dart --version`

2) flutter run không thấy Android device
   Nguyên nhân: chưa bật emulator / chưa cắm điện thoại
   Xử lý:
     flutter devices
     Android Studio → Device Manager → Start emulator

3) App không gọi được API (Android Emulator)
   Nguyên nhân: Backend chưa chạy, hoặc đã đổi baseUrl thành localhost
   Xử lý: chạy Backend port 5199; Android emulator cần 10.0.2.2 (đúng với api_config hiện tại)

4) App không gọi được API (Chrome / Windows)
   Nguyên nhân: Backend chưa chạy, hoặc đã sửa tay baseUrl thành 10.0.2.2
   Xử lý: source mặc định localhost cho non-Android; giữ vậy và chạy Backend 5199

5) App trên điện thoại thật không gọi được API
   Nguyên nhân: Android thật vẫn dùng 10.0.2.2 trong api_config
   Xử lý: đổi baseUrl thành http://<IP-LAN-máy-Backend>:5199
          cùng Wi-Fi; tường lửa Windows cho phép port 5199

6) Port 5199 bị chiếm
   Nguyên nhân: Backend cũ còn chạy, hoặc process khác dùng 5199
   Xử lý: đóng process cũ, hoặc đổi Urls rồi cập nhật mọi ApiBaseUrl/baseUrl
   Không force-kill Backend.exe đang lock 5199 trừ khi được giao.

7) dotnet run / restore lỗi thiếu SDK
   Nguyên nhân: chưa cài .NET 10 SDK (csproj TargetFramework = net10.0)
   Xử lý: cài .NET 10 SDK, kiểm tra `dotnet --version`

8) Web chạy nhưng không load dữ liệu
   Nguyên nhân: Backend chưa chạy, hoặc ApiBaseUrl sai
   Xử lý: chạy Backend trước; giữ ApiBaseUrl = http://localhost:5199

9) Database SQLite không tạo
   Nguyên nhân: Backend crash trước EnsureCreated, hoặc không quyền ghi thư mục
   Xử lý: chạy `dotnet run` từ thư mục Backend, xem log
          Không cần tạo file .db thủ công
          Không xóa carrental.db trừ khi được giao

10) Chuyển SQL Server thất bại
    Nguyên nhân: vẫn để DatabaseProvider = Sqlite; connection string sai;
                 chưa chạy script Database/
    Xử lý: chỉ làm nếu thật sự cần SQL Server.
           Chạy 01 → 02 → 03. Sửa DatabaseProvider = SqlServer và DefaultConnection.

11) Flutter Android build lỗi Gradle / CMake / file lock (Windows)
    Nguyên nhân: antivirus khóa file build (repo đã có script)
    Xử lý (chỉ CustomerApp):
      cd CustomerApp
      powershell -ExecutionPolicy Bypass -File .\run_android.ps1
    Hoặc:
      powershell -ExecutionPolicy Bypass -File .\setup_build_junction.ps1

12) CustomerApp cài lên điện thoại ARM thất bại
    Nguyên nhân: android/app/build.gradle.kts có abiFilters.add("x86_64")
    Xử lý: dùng emulator x86_64, hoặc sửa abiFilters cho đúng kiến trúc máy
           (cấu hình Android hiện tại, không phải lỗi Flutter SDK)

13) flutter clean khi build hỏng
      cd CustomerApp
      flutter clean
      flutter pub get
      flutter run
    Làm tương tự với DriverApp.

14) HTTPS redirection
    Backend/Program.cs có app.UseHttpsRedirection()
    Client đang dùng http://localhost:5199
    Nếu gặp redirect/SSL: dùng URL HTTP port 5199 như cấu hình hiện tại.

15) dotnet restore Backend cảnh báo NU1903
    Warning Microsoft.OpenApi (gói kéo theo OpenApi 10.0.3)
    Restore vẫn thành công (exit code 0). Không chặn chạy.
    Không tự ý đổi package version trừ khi được giao.

16) dotnet test / build MSB3027 copy Backend.dll
    Nguyên nhân: Backend.exe đang chạy (thường port 5199)
    Xử lý: test -c Release; hoặc dừng instance test. Không kill API chính nếu đang dùng.

17) POST /api/payments 400 "Đơn này đã có khoản cọc..."
    Đúng hành vi: một đơn chỉ một Deposit Pending hoặc Paid.

18) Đánh giá SelfDrive thất bại
    Backend CreateReview yêu cầu TripAssignment. SelfDrive không có assignment.

19) Complete SelfDrive / Driver 400 "đã có biên bản trả xe"
    Mỗi đơn một Return. Complete lần 2 bị chặn (cũng chặn nhân BookingFee).
